# UI/UX 重構規格 — OMNI-TWIN 殼 × 臨床安全核心

版本 1 ・ 適用 repo record-follows-person ・ 取代 CLAUDE.md §7 的白色單一主題（2026-09-05，使用者提供）

參考畫面：OMNI-TWIN「超個體動態生命操作系統」——深色殼、左側五大生命維度 rail（01 活體數位孿生／02 風格美學與形態／03 心理情緒與飲食／04 全資產與生命週期／05 照護與醫療艙）、頂欄地點·天氣·同步燈·頭像、中央人體圖＋右側維度面板（大數字、趨勢線、四格指標、一句建議）。

---

## 0. 一句話
**外殼是一個人的生命作業系統，核心是一條經得起醫療審視的照護鏈。**
殼可以科幻，鏈不能。所有設計決定都用這句話判斷。

---

## 1. 設計原則（先於任何畫面）
1. **兩種語氣，一條界線。** 本人自看的頁面（wellness）可以有分數、趨勢、建議；任何進入照護鏈的頁面（家屬、護理師、醫師）只有觀察、來源、確認。界線就是 05 艙的門。
2. **三秒法則。** 護理師每個畫面三秒內要看到：誰、什麼變了、我要做什麼。做不到就砍元素。
3. **來源永遠可見。** 每一句 AI 產出的文字旁邊，一眼分得出是照護者說的、AI 抽的、還是人確認的。深色主題下這條靠形狀（虛線／實線／勾）不靠顏色。
4. **紅燈壓過一切。** 紅燈出現時，任何頁面頂部都被它佔據，不能被關掉，只能被護理師「已處理」。
5. **夜班可讀。** 深色是為了夜班護理站與床邊手機。所以深色不是風格選擇，是使用情境，對比要照臨床螢幕的標準（數字 ≥ 7:1）。
6. **發光只給生命。** 只有 01 人體圖的熱點與同步燈可以發光，因為它們代表「活著、在更新」。按鈕、卡片、文字一律不發光。
7. **手機是照護者的，桌機是護理站的。** 不做「同一個版面縮小」，做兩套版面共用元件。

---

## 2. 資訊架構
```
OMNI-TWIN（殼）
├── 01 活體數位孿生     本人視角，八維度人體圖，wellness 語氣
├── 02 風格美學與形態   第二階段（導覽存在、頁面空）
├── 03 心理情緒與飲食   第二階段
├── 04 全資產與生命週期 第二階段
└── 05 照護與醫療艙     現有產品全部在此，臨床語氣
     ├── 本人艙      /me
     ├── 家屬艙      /caregiver  →  /p/{id}?tab=talk
     ├── 護理站      /nurse      →  Clinical Queue → 事件資訊包 → 審核
     └── 醫師艙      /doctor     →  巡診名單 → RoundPage（白底列印）
```
**進入點**：登入後直接落在 01（本人）或 05 的某一艙（依身份）。五維度 rail 永遠在，但 02–04 灰階，點了只顯示「第二階段」。
**病人頁 `/p/{id}` 不變**，仍是四個 tab（who / timeline / docs / talk），是所有艙的終點。

## 3. 外殼規格
### 3.1 桌機（≥ 1024px）
```
┌─────────────────────────────────────────────────────────┐
│ 頂欄 64px：品牌 ｜ 地點·天氣（假資料） ｜ 同步燈 ｜ 本人頭像 │
├──────────┬──────────────────────────────────────────────┤
│ 左 rail  │ 麵包屑 OMNI-TWIN / 05 照護與醫療艙 / 護理站     │
│ 240px    │                                              │
│ 五維度   │ 內容區                                        │
│ 01–05    │                                              │
│          │                                              │
│ 底：資料 │                                              │
│ 完整度   │                                              │
└──────────┴──────────────────────────────────────────────┘
```
- rail 項目：圖示 40px 圓框 + 名稱 + 英文小標（0.12em 字距）。選中項左側 3px --accent-2 指示條。
- 「資料完整度」條：顯示 FHIR-lite 對應率與來源數，不顯示任何健康分數。
- 紅燈橫幅：出現時插在頂欄之下、內容區之上，全寬，--danger 底 10% 透明 + 左側 4px 實線。

### 3.2 手機（≤ 430px）
- 頂欄 56px：只有品牌縮寫與本人頭像。
- 底部 tab 5 格：01 孿生 ｜ 05 對話 ｜ 05 事件 ｜ 05 紀錄 ｜ 我。02–04 不出現在手機。
- 紅燈橫幅固定在頂欄下方，內容區往下推，不遮輸入列。

## 4. 各艙畫面
### 4.1 01 活體數位孿生（本人）
**目的**：讓本人三秒看懂「我的身體今天哪裡跟平常不一樣」。
版面：左 55% 人體 SVG 線稿，右 45% 維度面板。
人體圖：
- 線稿用 --ink-2 20% 透明，熱點 8 個對應八維度（頭＝認知，頭側＝睡眠，胸＝生命徵象，腹＝進食飲水，骨盆＝排泄，腿＝活動功能，背＝皮膚，浮動＝疼痛依部位）。
- 熱點狀態三種：與基線一致（--accent 靜態）、有變化（--accent-2 呼吸動畫 2s）、紅燈（--danger 不動畫，因為要嚴肅）。
- 點熱點 → 右側面板切換，人體不重繪。
維度面板：
- 標題行：維度名 + 一句狀態（「比平常少吃一半，第 3 天」）。
- 大數字一個（wellness 允許）：今天的值。
- 14 天趨勢線：--accent-2，基線區間用 --line 淡帶。
- 最近一筆照護者原話（引號、--ink-2）。
- 底部一句 wellness 建議（只在本人頁允許，來源標「一般建議」）。
底部 tab：八維度橫向滑動，選中放大。

### 4.2 05 本人艙 `/me`
五段直排，手機單欄、桌機兩欄：
1. 狀態一行（穩定／有變化／護理師處理中）
2. 今天八維度（8 個小卡，每卡只有名稱＋一個詞）
3. 終身摘要（幾個病、幾次住院、幾年紀錄）
4. 最近事件（3 筆，點進事件資訊包的本人版）
5. 問我的紀錄（輸入框，回答每句附來源行；不給建議）

### 4.3 05 家屬艙 `/caregiver`
- 首頁：我照顧的人（1 張大卡）＋今天狀態＋警示＋「聯絡照護團隊」。
- 對話 `/p/{id}?tab=talk`：LINE 式，氣泡、底部輸入列（麥克風＋文字），agent 回覆前顯示活動列（日常語氣），可展開。
- 事件時：系統訊息＋四鍵（全系統唯一的按鈕），選完進追問。
- 紅燈時：只顯示「已通知護理師，請留在他身邊」。
- **不顯示**任何分數、百分比、感測原始值。

### 4.4 05 護理站 `/nurse`（桌機優先，深色為主）
Clinical Queue 三段，固定順序：
1. **新事件**：事件卡＝住民、事件類型、感測原始值（靜止秒數、SpO₂、心率前後，這裡是唯一顯示處）、照護者目前回報、「開啟事件資訊包」。
2. **待審核**：草稿卡＝住民、S 一行、A 一行、三鍵「確認／改一句／退回」，改一句就地展開輸入，不鎖其他鍵。
3. **今日總覽**：住民列表，每列八維度小點，有變化者亮 --accent-2。
事件資訊包（審核頁）：
- 左 45%：照護者區塊（原話、AI 抽取欄位虛線框）。
- 右 55%：護理師區塊（現場評估表單、ISBAR，A/R 欄空白待填）。
- 底部固定：確認、退回、路徑選擇（特約醫療機構／在宅急症／陪同就醫／觀察）。
- 確認後整包變實線＋--ok 勾＋確認人與時間。

### 4.5 05 醫師艙 `/doctor`
- 巡診名單：每列住民、本期變化一行、「看一頁」。
- RoundPage：**白底**（列印用），四段固定，深色殼裡以白色卡片呈現，右上「列印 A4」。
- 縱向摘要（RoundPage 上方）：慢病、用藥、住院與手術年表、近期事件。
- **不顯示**分數、機率、建議。

## 5. 元件系統
| 元件 | 規格 |
|---|---|
| 卡片 | --surface，1px --line，圓角 12px，無陰影，內距 20px |
| 二級卡片 | --surface-2，用於卡片內的卡片 |
| AI 草稿 | 1px 虛線 --accent-2 40%，底 --accent-2 8%，左上小標「AI 草稿，請確認」 |
| 人確認 | 1px 實線 --ok，右上 --ok 勾＋確認人＋時間 |
| 紅燈橫幅 | --danger 10% 底，左 4px --danger，文字 --ink，不可關閉 |
| 系統訊息（對話內） | 置中、--ink-2、13px、無氣泡 |
| 活動列 | 摺疊一行「花了 2.3 秒，4 步」；展開每步一行，紅燈步驟 --danger |
| 大數字（僅 wellness） | Inter 600，40px，--accent-2 |
| 臨床數字（護理站／醫師） | JetBrains Mono，20px，--ink，對比 ≥ 7:1 |
| 按鈕主 | --accent 底、--bg 字、高 48px（手機 56px） |
| 按鈕次 | 透明底、1px --line、--ink |
| 危險按鈕 | 只有「退回」「撤銷」，--danger 外框 |
| 標籤 | 小型大寫，0.12em 字距，--ink-2 |
| 趨勢線 | 1.5px --accent-2，基線帶 --line 30% |

## 6. Tokens（§7-dark）
```
--bg        #0B0F14
--surface   #121822
--surface-2 #182130
--line      #223042
--ink       #E6EDF3
--ink-2     #8FA3B8
--accent    #35E0C8   系統、正常、同步
--accent-2  #A78BFA   本人維度、01 孿生、AI 草稿邊
--ok        #3DDC97
--warn      #F5B84A
--danger    #FF6B6B
字體：Noto Sans TC（中文）、Inter（拉丁與大數字）、JetBrains Mono（臨床數字）
間距：8pt grid；圓角 12px；卡片無陰影
發光：只在 01 熱點與同步燈，box-shadow 0 0 24px color 35%
白色主題：RoundPage、事件資訊包列印版、醫師頁可切換，沿用原 §7
```
對比檢查：--ink on --surface = 12.8:1；--ink-2 on --surface = 6.1:1（正文可）；--accent-2 on --surface = 5.9:1（大數字可，小字不可，小字改 --ink）。

## 7. 動態
- 只有四種動畫：熱點呼吸（2s，僅有變化時）、活動列逐步出現（每步 120ms）、紅燈橫幅滑入（200ms，一次）、tab 切換淡入（120ms）。
- 沒有頁面轉場、沒有粒子、沒有掃描線。
- `prefers-reduced-motion` 全部關掉。

## 8. 狀態與空態
| 情況 | 顯示 |
|---|---|
| 沒有今天的紀錄 | 01 熱點全部靜態 --ink-2，面板寫「今天還沒有人記錄」 |
| LLM 失敗 | 對話內紅字系統訊息「系統暫時無法回覆，請直接告訴護理師」，不退回規則版 |
| 未獲授權 | 該 tab 顯示鎖圖＋「未獲授權」＋「向本人申請」 |
| 護理師超時 | 待審核卡變 --warn 邊，標「已升級至護理長」 |
| 列印 | 只印 RoundPage，白底，隱藏殼 |

## 9. 遷移順序（給 Claude Code，每步一個 commit）
1. tokens 與主題切換（dark 預設、white 保留），全站字體與對比先過。
2. 殼：頂欄、左 rail、麵包屑、底部 tab；02–04 空頁。
3. 05 四艙搬進殼，路由不變，先不改內容。
4. 元件替換：卡片、AI 草稿、人確認、紅燈橫幅、活動列。
5. 護理站 Clinical Queue 重排＋事件資訊包左右版面。
6. 01 人體圖與維度面板。
7. /me 五段與問我的紀錄。
8. 手機版面：底部 tab、talk、/caregiver。
9. 列印白底驗證、對比稽核、截圖進 ACCEPTANCE。

## 10. 不可違反（併入 CLAUDE.md §1）
- 分數、百分比、生理年齡、活力值、建議語句：只允許在 01 與 /me 的 wellness 區。
- 05 艙內家屬、護理師、醫師頁面：不出現任何分數、機率、信心值、建議。
- 感測原始值只在護理站新事件卡。
- 紅燈橫幅不可關閉，只可由護理師標「已處理」。
- RoundPage 與事件資訊包列印版白底。
- 四鍵是全系統唯一的按鈕式回覆。
