## 錄製前
```bash
make db-local && make migrate && make seed && make api   # 另一個終端 make web
```
- 瀏覽器用 Chrome（Web Speech API，zh-TW）；沒麥克風就打字。多語為第二階段。
- `/nurse` 每 5 秒自動更新；錄影前 `make reset`（重建 DB＋records＋seed，也清掉對話與舊 thread）。角色用右上「切換角色」。
